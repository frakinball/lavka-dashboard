# Дашборд заказов клиента «Сова-минималист»

Интерактивный HTML-дашборд на **d3.js** и **Vue.js** по датасету первой недели (вариант C).

## Что есть на дашборде

| Критерий | Где |
|---|---|
| Текущее значение основных метрик и динамика за 24 месяца | Карточки KPI (последний месяц, изменение к прошлому месяцу и к среднему, спарклайн) + блок «Динамика за последние 24 месяца» (заказы, траты, средняя скидка с общим курсором и тултипом) |
| Потребление по позициям в штуках и в деньгах | Двусторонний бар-чарт: слева — штуки, справа — рубли; сортировка, топ-N, период |
| Картинки на графике | Фото товаров из архива Items прямо в строках графика и в тултипе |
| Тултип с динамикой цены | Наведение на позицию: статистика + график цены за штуку (без скидки / заплачено) |
| Список категорий с метриками | Таблица категорий: траты и доля, заказы, штуки, средняя цена, средняя скидка, спарклайн трат, фото топ-товаров |
| Фильтр по категориям | Чипсы вверху (можно выбрать несколько) или клик по строке категории — фильтруются все блоки |

## Определения метрик

- Учитываются только **доставленные** заказы (отменённые исключены).
- **Количество заказов** — уникальные номера заказов в месяце (при фильтре — заказы, где есть товары выбранных категорий).
- **Сумма трат** — Σ «Сумма» по строкам.
- **Средняя скидка** — Σ(цена без скидки − цена со скидкой) × кол-во / Σ цена без скидки × кол-во.
- «Текущее значение» — последний месяц в данных (август 2026).

## Структура

```
index.html        — разметка (Vue-шаблон)
css/style.css     — стили, светлая и тёмная тема
js/app.js         — логика: Vue (состояние, фильтры) + d3 (графики)
js/data.js        — данные из xlsx в виде JS (работает без сервера)
js/images.js      — фото товаров из архива Items, встроенные в один файл
img/items/*.jpg   — те же фото отдельными файлами (необязательно, для справки)
```

## Запуск

Откройте `index.html` в браузере — сборка не нужна (d3 и Vue подключаются с CDN).

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него `index.html`, `README.md` и папки `css` и `js` (файл `index.html` должен лежать в корне). Папку `img` загружать не обязательно — картинки уже внутри `js/images.js`.
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту дашборд будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
